# IoT

Home IoT projects, one per folder. Each has its own README.

| Project | What it does |
|---|---|
| [Aircraft-Noise/](Aircraft-Noise/) | Measures how loud aircraft are at home: two ESP32 microphone nodes and a Raspberry Pi with an ADS-B receiver, plus the analysis and the aircraft classifier trained on the data. No audio is ever recorded. |
| [Sonos-Test/](Sonos-Test/) | Plays a sound on the Sonos speaker from the Pi (a test for aircraft announcements). |
